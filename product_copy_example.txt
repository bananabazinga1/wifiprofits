HOW TO USE:
1. Create a file called product_copy.txt in the project root
   (or set PRODUCT_COPY_FILE=/path/to/your/copy.txt in your .env)
2. Paste the raw text from your product's sales page into that file
3. For campaign mode, you can also pass it directly:
       python generate_campaign.py --days 7 --product-copy my_product.txt

The AI will read the copy and extract:
  - Product name
  - Core promise / headline benefit
  - Key features and how they work
  - Bonuses and their values
  - Pricing and any urgency/scarcity
  - Guarantee details
  - Social proof / testimonials

No special formatting required — plain text is fine.
The more complete the copy, the more accurate and specific the emails will be.

Each time you start a new campaign for a different product, simply point to
a different copy file. Your other settings (affiliate link, sender name, etc.)
stay in .env as usual.
